# 理工恐怖故事 · HLG

以中国高中为背景的校园恐怖探索游戏。当前可玩版本是 **HLG 0.2.0，Windows x64 原生程序**。

## 下载游玩

[下载 Windows 版](https://github.com/green-heart-group/sj-HLG/raw/refs/heads/master/releases/v0.2.0/HLG_Demo_0.2.0_Windows_x64.zip)，解压后双击 `HLG.exe`。无需安装 Rust，也不需要浏览器或联网。压缩包内有游玩说明、攻略、策划案对照和验证记录。

0.2.0 支持开局车卡与成长，使用属性、行动牌、支援手牌和骰子完成移动、探索与战斗。表世界保留 68 个原稿节点；里世界有 16 区、1101 个空间节点，会在探索中反复重组。

这是可玩的阶段版本。完整路线验证覆盖「循环」结局；原稿全部支线、成就触发链和其他结局的完整流程仍有缺口，详见上面的状态说明。

此前的 [HTML 演示](demo/demo-v2.html) 和 [原策划文档](docs/design/index.md) 继续保留，其进度单独记录。
