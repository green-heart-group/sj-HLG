HLG Demo 0.2.0 — Asset provenance

All scene and portrait artwork was redrawn to the user-requested 21st-century Chinese secondary-school setting.
Tool: built-in image_gen; no API/CLI fallback.
Two scene atlases, each 1536 x 1024 in a 3 x 4 layout, provide 24 images across 12 scene families and two worlds.
The portrait atlas is 1536 x 1024, 5 columns x 3 rows: five facial poses at three injury levels.
The runtime uses filtered scene sampling, a gamma shader and alpha-aware sprite rectangles. The source bitmaps remain intact.
The alternate world uses the same campus architecture, changing lighting, damage and geometry.
The title and all guide screenshots use these final embedded assets. Earlier artwork is excluded from this release.
No Doom textures, portraits, sound files or other third-party game art was copied.

The story and item/location names were adapted from the user-supplied HLG materials. This release is an adapted standalone chapter.

Animation and sound
Portrait pose selection, alternate-world tint, dead pixels, meter deformation and transitions are implemented in project code.
assets/surface.wav and assets/echo.wav are synthesized original ambient loops, played through Windows WinMM. No recording was sampled.

Font
assets/NotoSansSC.ttf is a static weight-450 subset derived from Noto Sans SC, internally renamed HLG Game Sans.
Upstream: https://github.com/google/fonts/tree/main/ofl/notosanssc
License: SIL Open Font License 1.1; complete text included in assets/FONT-OFL.txt and the distribution licenses directory.

Software dependencies
Versions are pinned in Cargo.lock. Original license texts and package declarations are collected under licenses.
native/windows-gnu/libimm32.a is an unmodified alias of the winapi GNU import library; winapi MIT/Apache license texts are included.
