# HLG 0.2.0 游玩说明与攻略

解压演示包，双击 **HLG.exe**。这是完整可走通的八信物章节，保留表里世界探索、战斗、成长与死亡循环。先创建角色；右侧指引会随实际进度更新。卡牌预览不会扣资源，只有确认后才执行动作与结算。

## 第一次进入校园

1. 四项属性各为 1–5，合计 12。初见可用「均衡」3/3/3/3；「观察」2/3/5/2 更容易核实里世界道路。「机动」擅长移动和防御，「定心」减少精神检定压力。体魄决定生命，机敏决定体力与物理防御，洞察用于查看和对读，定力用于穿镜、精神防御和最后的祭坛。
2. 点地图上的**传达室**，选择移动牌，读清消耗后确认。进入后选「阅读离校须知」。从这里开始，目标是八件信物。
3. 每个角色行动都有过场。动画之后，左侧回执写明实际差值，右侧告诉你下一步。新物品、遭遇、死亡和地图重组会打开详细回执；阅读、翻页、关闭回执都不推进回合。
4. 顶栏列出持续状态。皂化会每回合额外耗体力，牛奶可以解除；寒流会增加移动消耗。别只看行动牌的基础消耗，还要看状态与实际回执。

| 按键 | 用途 |
|---|---|
| 鼠标点地图 | 选择目标，再选可用移动卡；不是直接传送 |
| 1–5 | 打开本页第 1–5 张行动牌 |
| Enter / 空格 | 确认预览中的行动，或关闭结果回执 |
| B | 背包：查看、持握、使用与制作 |
| I / J | 档案与手记 |
| A | 成就页 |
| C | 人物卡与成长 |
| V | 上次行动的完整回执 |
| M | 地图回到当前地点所在楼层或区段 |
| Esc | 返回或暂停 |

## 牌、骰子和成长怎样配合

手牌不是所有行动的限制。现场行动、移动、已取得道具的用途一直可选；三张支援手牌可以给其中一次行动加值。投入后才会弃置并补一张，牌库耗尽再洗弃牌。查看牌面和更换选择不消耗牌。

| 支援牌 | 实际效果 | 适合时机 |
|---|---|---|
| 细看一遍 | 洞察 +2 | 查看地图、核对记录、部分解救判定 |
| 放轻脚步 | 机敏 +2 | 普通移动、引魂钓打捞与救人 |
| 稳住心神 | 定力 +2，精神防御骰 +2 面 | 穿镜、黑域祭坛、精神攻击 |
| 抓住空隙 | 体魄 +2，攻击骰 +2 面 | 对复制体或被同化者出手、破祭坛 |
| 留出退路 | 本回合防御骰 +3 面 | 准备承受敌人一次攻击 |

普通移动用 d6+机敏。失败仍会到达，发生遭遇后可能额外耗一点体力。攻击掷出的数值与敌方防御骰比较，只有正差造成伤害。盲目向不能战胜的教师实体连续攻击，通常不如使用相应器物或离开。

新地点、首次线索和关键物品提供阅历，每 8 点升一级，最多 9 级。C 页分配成长点。探索阶段提高洞察与机敏，面对精神伤害和最终祭坛前补定力；需要正面战斗时提高体魄。成长与剧情在本局死亡后继续，开启全新循环才重新车卡。

## 固定表世界和变化的里世界

表世界按 TXT 地名和坐标建立，共 68 个展开地点。界面中的「地下 / 1–5 层」只切换查看楼层；真正上下楼仍需沿连线或用信物移动。一个点可能有多个房间，点击后选择。化学办公室与生物办公室都位于 (2,3,3)，这是批准勘误后的重叠，不是显示错误。

里世界有 16 个区段、1101 个空间节点，其中多数是重复出现的校园房间，豢养区入口暂未开放。目标房间的区段会显示在指引里；先用「逐处查看」核实本区，再循连线前进。区段门旁会出现「跨入第 N 区」，仍需确认移动卡。总览可查看各区已核实的地点数量，M 回到当前区。

道路会在以下时机重组：重新进入里世界、死亡、跨区之后、累计每 24 个里世界行动回合，以及主动「沿走廊折返」。跨区只重组刚离开的区段；24 回合和主动折返重组当前区。原来的路和地图标记可能失效，物品、剧情、已救出的人和成长不会因此重置。回执会列出改变的房间与通路数量。

每个区段都有学生公司休整处、喷泉镜面与楼顶。体力低先休整，理智低用「对读记录」或在安全处休整。里世界普通位置每个行动回合侵蚀 1 理智，站在安全处不会受到这项扣除。复制镜面会把你送回本次入场的表世界入口；原有镜面回到其原地点。

## 八件信物主线攻略（含剧透）

下面按便于准备物资的顺序写。地图会限制实际可用路径，不能照着坐标跨越没有连线的房间。里世界中的相应房间位置会改变，应以当前地图和指引为准。

1. **准备灯与补给。** 传达室读须知，去钟楼柜群取得墨水瓶、未知溶液、安全火柴和笔记本。选择制作自制酒精灯，持握它。到学生公司查看箱子，取得道具铁剑、铁盔甲、牛奶与饼干。去钟楼寄存物品清单。
2. **门卡与问津。** 到三层化学办公室 (2,3,3) 拿门卡，首次会送你到化学实验室并遭遇 WXH。用「灯火驱离」争取时间。再去四层高三一班 (1,3,4) 取得问津；持握问津可以抵御 LL。回钟楼更新寄存。
3. **引魂钓与一横。** 在喷泉等待倒影，确认穿镜入口。到小园林 (2,4,1) 取引魂钓，再去假山地牢 (2,4,0)，用钓竿打捞一横。钓竿不因失败消失，可投入机敏支援牌重试。
4. **雷跃。** 到二层物理实验室 (7,2,2) 取得雷跃和笔记。ZYY 会出现，不必硬拼。雷跃持握后可沿相同坐标向上移动，不需要先完成天雷充能。再次回钟楼寄存普通物品。
5. **制皂与香皂。** 穿镜，在里世界找到课程主任办公室，阅读备忘录并对付被同化者。持握铁剑，使用攻击牌，取得脂肪。回表世界化学办公间领取制皂材料；脂肪+不明溶液制作粗制肥皂。找到 WXH，使用粗制肥皂开启皂化池剧情。进入里世界皂化池，按记录实验：本次角色死亡并重生，d7=7 才得到细研香皂，其余是精制肥皂。信物、剧情和成长保留。此处采用原案详细条款的 1/7 机制，重复实验属于预期流程。
6. **二倍体。** 在里世界进入标本馆，先从背包选「腾出双手」，再取标本。复制体出现后可以持握二倍体应对，也可离开。二倍体增加体力上限，却会让移动多耗体力，长途赶路时可以收起来。
7. **骨轮。** 到里世界炼功房取骨轮。HJF 出现时要留意精神伤害。本章骨轮飞行在里世界明确的复制楼顶之间进行，需持握、燃油和楼顶起降；它很适合越过复杂的里世界道路，背包里的燃油不会自动消耗。
8. **石靴。** 回表世界四层地理办公室 (3,3,4)，领取矿料与煤炭。先投矿料，再用三块煤炭点亮三座高炉，获得石靴和两把深渊之钥。
9. **黑域与离校。** 带其余七信物去二层校长办公室 (5,2,2)，用定力检定取得浮寰黑域。失败会损失理智；低于安全余量时先对读记录恢复，不要连续硬试。取得八件后去传达室交付；第一次触发喷泉剧情并回到大厅，再去交付一次才能开门。最后到校门口确认离校。

上述路线若没有启用结局道具，结局为「循环」。死亡后先看回执确认回到哪里，打开背包核对寄存物；普通物品按最近一次钟楼清单恢复。需要时再到柜群和相关补给点准备材料，不要默认死亡后仍在刚才的房间。

## 道具的实际用法

器物与信物只能同时持握一件。持握不推进回合，因此可先换好再出牌。门卡、材料、引魂钓、钥匙和结局条件按各自用途携带；背包的说明按钮会指向当前可用的行动或配方。

| 物品 | 关键用途 |
|---|---|
| 酒精灯 | 对 WXH 击退，不烧燃油；有机会解除皂化 |
| 问津 | 抵御 LL 精神伤害与寒流 |
| 细研香皂 | 沿两段实际连线滑步，仍受终点门禁限制 |
| 怒霆雷跃 | 同坐标向上；充能和雷枪是另一项用途 |
| 二倍体 | 对复制体同化攻击；体力上限增加但移动更累 |
| 一横 | 本层十字视野；用黏痰发射直线攻击 |
| 石靴 | 留下深坑，阻挡追踪 |
| 骨轮＋燃油 | 楼顶之间飞渡 |
| 黑域 | 吸引相邻实体并攻击 |
| 牛奶 | 解除皂化和寒流 |
| 金色槐叶 | 持握时挡住一次致死伤害，随后消耗 |
| 引魂钓 | 地牢打捞、特定地点救人；不是消耗材料 |

配方包括酒精灯、粗制/精制肥皂、灵敏电流计、融联剂及三种结局物。配方缺料时会显示缺项，确认按钮不会放行。骨轮、雷跃等移动方式需先在地图选择目标，才会出现相应移动牌。

## 成就、文献与其他结局

普通成就页按已点亮与相邻主线显示，未点亮的描述和彩蛋保持隐藏。「原稿目录」另列 99 项全文，提示含剧透；其中 51 项接入触发、48 项未开放，查看原文不会解锁。原稿中尚未完成的文字也照原样保留。长手记和场景支持分页，阅读不推进回合。

结局优先级依次为：七滴生魂之泪的「仁主」；合成深渊信物的「堙灭」；四次天雷庇佑的「干枯」；启用你的手记的「公之于众」；启用虚无造物的「逃离」；没有上述选择的「循环」。手记与虚无选择不可同时启用。

本版已经验证六种条件的优先级，但仅「循环」有完整路线验收。可选结局支线、完整 NPC 剧情、豢养区、全部隐藏纸条与成就前置链仍有缺口，具体状态见「策划案对照」。不要把原稿目录里的未开放条目当作本版必做目标。

## 保存与排查

每次结算后自动保存。Windows 存档目录为 `%LOCALAPPDATA%\HLG-NightSchool-v2`，与 0.1.x 分开。钟楼寄存决定死亡后恢复哪些普通物品，不等于程序的自动保存。点击「开始新循环」会重开本局；已有进度时需再点一次确认，档案保留。

暂停页可调整亮度、关闭环境音、减少动态效果。默认 Gamma 2.2，界面文字不受图像亮度调整影响。

如果找不到可走的路：先按 M 回当前地图，检查是否选错楼层/区段；里世界使用逐处查看；重叠圆点先选择具体房间；再查看移动牌的门禁提示。如果资源变化多于牌面基础消耗，查看顶栏状态和 V 回执中的持续效果说明。
