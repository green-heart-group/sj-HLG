# Demo 进度与已知问题

更新时间：2026-07-31（迁入本仓库：2026-10-20）

[demo/demo-v2.html](../../demo/demo-v2.html) 是《理工恐怖故事 / HLG》的 HTML 单文件原型：把原 Minecraft 策划案中的地点、物品、成就、教师实体、事件、商店、战斗等内容做成可浏览、可交互的文字节点游戏。以 `demo-v2.html` 为准，不是旧版 `index.html`。

## 运行

纯 HTML/CSS/JavaScript，不依赖网络和第三方包，浏览器直接打开即可。若浏览器阻止本地文件脚本，在 `demo/` 下启动静态服务后访问 `http://localhost:8000/demo-v2.html`：

```powershell
uv run python -m http.server 8000
```

## 已完成

### 地图与节点

- 按[机制草案](mechanics-draft.md)中的坐标生成节点拓扑；连线由坐标相邻关系自动生成（同层曼哈顿距离 1，或同坐标上下楼）。
- 节点类型：探索、事件、战斗、商店、安全、锁定、结局。
- 支持同坐标多个地点（如实验室组）、进入节点、返回地图、节点预览与行动日志。

### 背包与物品

- 左侧背包 10 格快捷栏；支持堆叠、拾取、使用、装备/持握。
- 已有物品：波波的门卡、备课笔记、学长手记、问津、空墨水瓶、安全火柴、未知溶液、自制酒精灯、矿泉水、威化饼干、怒霆雷跃、一横圣器、黏痰、引魂钓、燃油、醇类物质等。
- 已实现部分行为：饮用/食用恢复体力；酒精灯、一横圣器、问津、怒霆雷跃可切换持握。

### 商店节点

- 自动售卖机货架为 2 排 × 4 列共 8 格，每格显示物品、数量、价格、购买按钮；售空格降透明度。
- 悬停显示物品名称、类别、堆叠上限与售价。
- 学生食堂与实验楼廊道使用不同货架池。

### 成就树

- 主线成就 85 条，从[原策划案·成就系统](../design/achievements.md)「Root：主线成就」至「Root：彩蛋成就」之前抽取：名称、图标、文本内容、达成条件、前置成就、隐藏标记。原案中的占位文本（如「于是」「那」「由」）原样保留。
- 悬停提示显示：名称、是否获得、图标字段、文本内容、达成条件。
- 自动布局：同层重叠 0；单子节点的父节点 18 个，均用直接横线。
- 连线规则：只有一个子节点且父子同 y 时用直接横线；否则用正交折线。

### 信息系统

- 有信息弹窗框架，按分类展示已解锁信息。
- 已接入部分事件与物品信息解锁，如 WXH、LJX、MJ、酒精灯合成信息。

### 战斗节点

- 基础原型：观察敌对实体（消耗理智、解锁信息）；掷骰攻击/击退（按装备与实体设定计算）；逃离（消耗体力）。
- 教师实体占位：化学实验室 WXH、物理实验室 ZYY、地理办公室 SGF。
- 仍是简单掷骰原型，不是最终玩法；方向见[后续计划](roadmap.md)。

## 已知问题

- 代码全部压缩在单文件中，尚未拆分数据与模块。
- 部分成就 ID 是自动生成的（形如 `ach_4388935`），尚未人工命名；需要存档兼容前应补稳定 ID 映射。
- 原案中部分前置名称与成就标题有符号差异（如「炮火连天？」与「炮火连天」），脚本已做部分归一化，新增成就时仍要注意。
- 只抽取了主线成就；彩蛋成就、场景收录、人物信息尚未接入。
- Edge headless 截图曾因沙盒 GPU 初始化失败而不可用，当时用 JS 解析与布局数据校验代替，需在浏览器中人工检查。
- PowerShell 控制台可能把中文显示为乱码，HTML 文件本身是 UTF-8，浏览器显示正常。
