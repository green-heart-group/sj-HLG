# 原策划案

《理恐MC-策划案（修订版）2022.9.29》，原为 Minecraft 解谜游戏策划。原件 docx 挂在 [issue #1](https://github.com/green-heart-group/sj-HLG/issues/1)；以下 Markdown 由原件逐段转换，保留原文字色（`<span style="color:…">`）、加粗、删除线，Word 批注以 `> [批注n]` 跟在对应段落后。修订以 Markdown 为准，docx 只作存档、不再修改。

条目前的符号（`+` `@` `~` `&` `#` `%`）和名词括号（〖〗｛｝『』〔〕〈〉「」）的含义见[附录](conventions.md)。

- [overview.md](overview.md)：策划背景、游戏概况
- [locations.md](locations.md)：特殊地点（主要地点、彩蛋地点）；手绘校园地图见 [issue #1](https://github.com/green-heart-group/sj-HLG/issues/1)
- [plot.md](plot.md)：剧情整理（主线、支线）
- [items.md](items.md)：相关物品（信物、结局走向、常规、权限、信息文本）
- [entities.md](entities.md)：实体机制（敌对、中立 NPC）
- [endings.md](endings.md)：结局类型
- [achievements.md](achievements.md)：成就系统（主线、彩蛋、场景收录、人物信息）
- [story.md](story.md)：故事背景（章回体回目与内容）
- [playtest-issues.md](playtest-issues.md)：实测问题（只有标题）
- [conventions.md](conventions.md)：附录：命名规范、引用格式、修订符号
