## 常规物品类

**（物品名称将根据其品质依次分为：**<span style="color:#BFBFBF">**耗材类、**</span><span style="color:#70AD47">**增益类、**</span><span style="color:#4472C4">**器物类、**</span><span style="color:#F4B083">**传说类**</span>**）**

**\*类别具体释义：**

<span style="color:#BFBFBF">**耗材类：**</span>**使用方式惟一且该方式会消耗其自身数量的物品，或在其它物品的使用过程中会被连带消耗的物品；通常为获取难度较低（较易大量获得）的物品或合成更高级物品的原材料。**

<span style="color:#70AD47">**增益类：**</span>**包含所有可食用或饮用，同时获得饥饿度提升或增益效果的物品。**

<span style="color:#4472C4">**器物类：**</span>**无法被消耗，或除消耗自身数量外仍存在其它用途的物品；通常为低级物品的合成产物、装备类物品、获取难度较**<span style="color:#BFBFBF">**耗材类**</span>**更高或更稀有的物品。**

<span style="color:#F4B083">**传说类：**</span>**包含较为稀有的一类使用效果显著的物品。**
