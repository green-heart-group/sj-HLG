# 策划背景

笔者及创作同僚曾有幸受教于理工附中的部分骨干、优秀教师，并于尚在该校就读之际，即基于上述教师们颇具特点的言行举止，加以一定程度的设想、填充及艺术化创作，衍生出“理工恐怖故事”蓝本。该蓝本以文段、短篇小说、诗词歌赋等文学形式刻意地**恐怖化**修饰了理工附中的一些办学及教师设定，受到小范围同学的欢迎与喜爱。

为了将上述设定具象化，以及分享给更多喜好理工附中及校园恐怖题材的玩家，笔者于2020年8月起，携手创作团队开始进行本游戏的策划及制作。相信在不远的未来，本游戏将作为首款将上述蓝本以**视觉化形式**呈现的新作，向广大玩家群体开放公测。

\*本游戏的定位为**“基于MC机制的恐怖风格解谜游戏”。**

\*本游戏使用的MC地图基于游戏昵称为<span style="color:#70AD47">**“木瓜味的屁”**</span>的老学长所制款式**理工附中线上毕业典礼MC地图；**由<span style="color:#0070C0">**晁老师**</span>作为特邀嘉宾（偶尔提供机制&剧情思路），并由**笔者**间断性创新细化、撰写策划案，再由<span style="color:#C45911">**老干部**</span>进行持续性定向加工及改造而成。

\-2022.9.7

# 游戏概况

玩家以**冒险模式**在理工附中（原京工附中）总校区的MC地图之中完成诸如**探索校园、躲避仙怪、揭秘真相**等一系列操作及任务，并最终完成逃脱。

\*逃脱的条件为集齐八位老师的**信物，**并置入学校门口的**信物回收盒**中等待开门。

\*在本游戏过程中，<span style="color:#FFC000">**【成功完成逃脱】**</span>和<span style="color:#7030A0">**【挖掘事实真相】**</span>将是两种截然不同的游戏难度，后者作为创作团队所鼓励的游戏难度，其所消耗的**时间、精力**及所能体验到的**趣味性**等要素远高于前者，是充分游玩、探索本游戏所有内容的惟一方式。（当然，若玩家已经成功探索全部事实真相，同样可以再次尝试<span style="color:#0070C0">**“最速通关”，**</span>刷新本游戏的最短用时记录。）

<span style="color:#E7E6E6">\*设计上的成功完成逃脱所用时间（下简称“通关时长”）对于新玩家为4\~5小时；理论最速通关时长为1小时左右；新玩家于不看攻略的前提下，收集满MC地图中全部隐藏彩蛋要素，并拼凑出关于每位老师的事实真相最速约为1\~2天。</span>
