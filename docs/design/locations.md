# 特殊地点

## 主要地点

\*名词释义：玩家为达成任何一个游戏结局（逃出校园）都必须历经的地点；这些地点通常随时对玩家开放，且在会在首次进入时为玩家提供**基本描述**，但也存在一些拥有**开启条件**的剧情地点；玩家须按照一定的顺序历经这些地点，完成这些地点所对应的任务、并获取通关所需的游戏道具，方能成功推进游戏进度。

**\*基本描述：在玩家首次踏足某剧情地点时会强制弹出的地点描述，将以简略的形式交代出此地点的设定背景及游戏机制等要素。**

\*开启条件：某剧情地点对玩家开放的条件，通常与已解锁的剧情或破解的谜题相关。

## 彩蛋地点

\*名词释义：玩家在达成**至少一种**游戏结局（逃出校园）的过程中完全不需要历经的地点；这些地点通常较为隐秘、或需要提供一定的**权限**方能进入，并包含一些额外的拓展任务以及彩蛋剧情，这些剧情将有助于玩家更好地理解游戏的背景设定。玩家在成功完成其中的一些任务后，可以获得少量品质较高的道具，这些道具将为接下来的游戏进程创造极大的便利。

**\*至少一种：本游戏为玩家提供多种结局可能性，详见“游戏结局.doc”；以下涉及的部分彩蛋地点可能与其中的小部分结局相关，但对于每个彩蛋地点，势必会存在至少一种游戏结局与此地点完全无关。**

\*权限：玩家在游戏过程之中拥有的权限主要通过所持有的权限类物品体现，目前的权限类物品包括：<span style="color:#F2F2F2">**『波波的门卡』**</span>（以下简称“白卡”）、**『校长的门卡』**（以下简称“黑卡”），以及耗材<span style="color:#C9C9C9">**『异变基因』**</span>。拥有“白卡”权限的玩家可以通过【唱片机机制】刷开部分特殊的铁门，而拥有“黑卡”权限的玩家可以刷开所有的铁门，『异变基因』则可以帮助玩家打开某扇【藤曼门】。<span style="color:#FF0000">**需要注意的是，标注了此类权限的彩蛋地点须在制作时三维封闭化处理，去除没有此权限者可以进入的一切途径（如使用铁门隔绝一切通路）。**</span>
