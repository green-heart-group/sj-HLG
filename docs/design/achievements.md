# @成就系统（监修中）

## 主线成就

\*名词释义：按照特定的逻辑顺序设置的游戏目标系列，主要作用为避免新玩家因无法找到后续游戏目标而无法推进游戏进度。**在进度选项卡内，无论是否被完成，所有主线成就均会被设置为**<span style="color:#FF0000">**可见**</span>**（这是为了方便玩家实时观察游戏进度）。**

**【实际受限于MC进度系统规则，仅有已解锁成就及其下两级的成就在游戏中可见。】**

\*注：本系列所提供的是其中一种符合逻辑的剧情发展顺序，玩家仍可按照任意自己喜欢的顺序进行游览，仅需在无法推进游戏进度时参考本系列“主线成就”。此外，本成就系列存在多种分支，**有些分支的内容不必完成，或须选择其一、放弃其余分支，方能推进游戏进度。**

**\*在游戏过程中，主线成就系列可能包含轻微的剧透信息。**
